## Pass when
- Validate evidence producer ownership in the write transaction: resolve run id to its owning attempt, and generation to that attempt’s persisted candidate. Compare persisted versions atomically and reject mismatched producers or superseded-run callbacks. Route late GitHub checks using persisted push ownership (attempt, generation, pushed head and publication identity), including identical heads reused across attempts; head equality alone cannot select an owner. Ambiguous callbacks update no attempt. Authorize the TODO and verify the named attempt references the digest before invoking blob retrieval

- Step 2, PR body (§12.5.1): diff stat (files, +/−), a checks table naming each machine check with outcome and duration, and the agent's review summary. The GitHub `ci` check shows on the PR's own checks.
- Step 2, TODO card: diff stat, machine checks, the GitHub `ci` check with its conclusion and `required`, the review summary, plus tokens, time, flow version and model access for attempt 1 (§10.4.3); shared values equal the PR body's.
- Step 4: the run records the model access it used (§15.2): the provider key or ChatGPT subscription, and the model id. It equals the model proxy's usage rows for that run and the TODO card's value.
- Step 3: the log opens and contains the check's output.
- The GitHub check status appears on the card within 60 s of GitHub reporting it (§12.2.3).
- Every evidence entry shown names one generation, the accepted one, and the PR head commit's tree equals that generation's candidate tree (`git rev-parse <pr_head>^{tree}`, §10.4.4).
- log_url is `/api/todos/{n}/attempts/{attempt}/logs/{digest}`. Referenced logs return text/plain 200; unrelated digests return 404 `{code: "not_found", class: "user"}` with zero blob reads. OpenAPI declares both responses.

## Fail when
- Evidence shows only on automerge items or only after merge (today's gap).
- GitHub checks are read from a head other than the PR's current head.
- The card shows a check row "not measured yet" or any placeholder (AGENTS.md minimal text).
- The run has no model access recorded, or one that differs from the usage rows.
