## Setup
- Thin path (tickets/README.md): T-INS-01 → T-INS-02 → T-INS-08; T-ACC-01 → T-ACC-02 → T-ACC-03 → T-STK-04; T-STK-01 → T-STK-12 → T-STK-04 and T-STK-01 → T-ACC-02. In S1 the operator installs with `smthrs host start --bundle` and holds the bundle README (T-INS-08); at R the install comes from T-INS-05 and the operator holds the T-DOC-01 quickstart.
- The reference host (the team's Mac mini, whatever its size) after Erase All Content and Settings, macOS 15 or later, Homebrew, no Smithers state. Host clock synced by NTP; the offset is recorded at start and end.
- Scratch repository `smithers-mvp-canary/<date>` from the canary template: squash merging enabled, a test command the toolchain detector finds, no `.smithers/` files, and `JOURNEY.md` with the fixed first TODO prompt.
- Owner account `canary-owner` with admin on the repository; a provider key and an AI Gateway key in the operator's password manager.
- Operator: a person who did not build the install tickets, holding only the bundle README (S1) or the quickstart (R). Nobody answers questions; a request for help ends the run as failed.

## Steps
1. Start the screen recording. T0 is the first keystroke of the install command (S1: unpack the bundle archive and start the launcher as its README says; R: `brew install smithersai/tap/smithers`, then `smthrs host start`).
2. Open the printed one-time setup URL (§5.1.0); complete setup steps 1 to 6 (§16.2).
3. Ask the app agent a question about the code; receive an answer with file cards.
4. Write the TODO from `JOURNEY.md`; place it with Append.
5. Wait while the TODO moves Queued, Starting, Working and In review (§4.1); open the TODO card's evidence and the PR.
6. Review in the app and press Merge.
7. T1 is GitHub's `merged_at` for the PR.

## Pass when
- T1 − T0 ≤ 60 min, using the recording's UTC clock for T0 and GitHub's `merged_at` for T1, corrected by the recorded clock offset.
- The recording shows no assistance.
- The PR head is `smithers/<slug>`, its base is `main`, and it was squash-merged as one commit on `main`.
- The merge came from Smithers' Merge: one `checks.Land` approval with a `session` credential and the reviewed head sha.
- The TODO shows Merged only after GitHub reported the merge (honest state, spec §19.3).
- Source ready appeared before the first answer, and Machine ready appeared as a separate step.

## Fail when
- The operator edits a configuration file, runs a command the README or quickstart doesn't show, or uses `pnpm dev`.
- The merge happens on GitHub instead of in Smithers.
- An engineer intervenes, including by chat.
- The run reuses a repository, an install or a model cache from an earlier run.
