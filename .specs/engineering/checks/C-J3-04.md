# C-J3-04 Two people co-edit one file

Proves: mvp.md J3.5, §6.8 Live co-editing, §9 Live updates, §12.1 (two writers' edits to one file), M-02 · spec.md §7.4.1–7.4.5, §7.6, §9.2.1–9.2.5, §18 · Layer: e2e · Stage: S3 · Tickets: T-COL-08, T-APP-14, T-UI-19
Automation: `apps/app/e2e/real/file-coedit.spec.ts` (new) · Runs in: reference host, browsers on a second Mac on the same network at the install's public origin

## Setup

- A fresh install at the commit under test. The scratch repository `smithers-mvp-canary/<date>` has `retry.ts` (80 lines), `big.json` (2 MiB) and `logo.png`.
- Ben and Alice signed in, in two browser contexts on one Playwright runner (one monotonic clock). Maya has SSH. Ben has a terminal open on the branch. TODO T2 is `working`, and its prompt asks the agent to add a comment to `retry.ts` line 70.

## Steps

1. Ben and Alice open `/file retry.ts`.
2. Non-overlapping: Ben types 200 characters on line 12 while Alice types 200 on line 40, both at 8 per second. Record each character's arrival in the other page.
3. Overlapping: both type 50 characters at the same position on line 20 at the same time.
4. Ben stops typing. Watch the header, then run `cat retry.ts` in Ben's terminal.
5. The agent writes line 70. Maya, over SSH, appends a line to `retry.ts` and saves.
6. Overlapping outside save: Alice types one character on line 30. Within 100 ms, before the 200 ms flush, Maya runs `sed -i '30s/$/ maya/' retry.ts` over SSH. Alice presses **Compare**.
6b. Ordering (a test build with the watcher delayed by 2 s, `SMITHERS_MACHINED_WATCH_DELAY_MS=2000`): repeat step 6 20 times with Maya's `sed -i` landing before the debounce fires, and 20 times with an in-place write (`printf … > retry.ts`) landing during the save.
7. Ben types 20 characters on line 50. When his header shows "Saved to the machine", restart the install (`smthrs host stop`, `smthrs host start`) and run `cat retry.ts` after it is back.
8. Both close the card. After 60 s, Alice reopens it.
9. Open `/file big.json` and `/file logo.png`.

## Pass when

- Step 2: each character reaches the other page in < 1 s p95 (n = 400, the runner's monotonic clock), in its author's colour, with a name flag on each remote editor's line and no caret or selection drawn.
- Step 3: both pages hold identical text containing all 100 characters, each run in its author's colour.
- Step 4: "Saved to the machine" shows within 1 s of the last keystroke, driven by the daemon's `saved` frame covering each page's own updates (§7.4.6). `cat` byte-equals both pages. Activity shows one entry per editor per 2 s idle period ("Alice edited `retry.ts`"), never one per keystroke.
- Step 5: both lines appear in both pages within 1 s of the disk write, and neither page loses its own unsent text. The agent's line is attributed "Agent". Maya's is attributed "Maya via SSH" when hers was the only active session during the burst, else "changed outside Smithers" (§9.3.1); the evidence records the session set.
- Step 6: the file on disk equals the document, and Alice's character is kept. Maya's version is her outside burst's `after` version (§9.3.4), and both pages show "Changed outside Smithers · Compare" (§9.2.3). Compare shows Maya's version beside the document.
- Step 6b: in all 40 runs Maya's version is merged into the document or kept as her burst's `after` version; none is lost, whichever came first, the watcher or the save (§9.2.2 step 4).
- Step 7: the 20 characters are in the file after the restart (§9.2.3a).
- Step 8: the reopened document equals the file on disk, with the same per-character authors as before closing (§9.2.5).
- Step 9: both files open read-only and show "too large to co-edit" (§9.2.1).

## Fail when

- Edits travel only on save or through a refresh (merge-on-save behavior, which M-02 rejects).
- Pages diverge after step 3, or a character appears twice.
- The header shows "Saved" before the file on disk equals the document, or an acknowledged save is missing after the restart.
- Maya's step 6 save replaces Alice's character, the flag is missing, or Maya's version can't be found in her burst's versions.
- An agent or SSH write replaces a page's text without attribution, or arrives as a reload that drops the other editor's position.
- `big.json` opens editable, or the card freezes on it.
