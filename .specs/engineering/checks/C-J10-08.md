# C-J10-08 PR closed on GitHub turns the TODO Dropped with its actor; reopen restores it

Proves: mvp.md §6.3 "A TODO's PR is closed without merging", M-22 · spec.md §4.1 (any unmerged → dropped, dropped → in_review), §10.2.3, §10.6.2a, §10.7.4, §12.3 (closed row) · Layer: integration · Stage: S1 · Tickets: T-GH-03, T-STK-05, T-MCH-14
Automation: `packages/backend/internal/services/github_inbound_pulls_integration_test.go` (new) · Runs in: CI for steps 1-3 and 5; reference host (real microVM, simulated clock) for steps 4-4c

## Setup
- Real PostgreSQL, real git and jj, and a real flow host running a fixture `todo` flow whose steps finish at once (pattern of `packages/backend/flowdispatch/real_host_test.go`). `githubfake` with three TODO PRs, for T1, T2 and T3 In review in that stack order, and its write log.
- T2's attempt 1 has flow digest D and accepted generation g2 with PR head P2, and its working copy holds an uncommitted file `notes.txt`.
- The scheduler under an injected clock.

## Steps
1. On the fake, user `alice` closes T2's PR without merging (`closed_by: alice`).
2. Advance one pulls cycle (60 s).
3. Deliver the same close again: a second poll result and a webhook hint.
4. Run the workspace reclaim sweep 24 h + 1 s after the close. At 25 h after the close, reopen T2's PR on the fake. Advance one cycle.
4a. Deliver the same reopen again: a second poll result and a webhook hint.
4b. Ben (Maintainer) posts a review comment on T2's PR. Advance one cycle and let the fixture run finish.
4c. Ben merges T1, then T2, through `POST /api/todos/{n}/merge` at each one's current PR head, letting T2's rebase and recheck finish in between.
5. Close T3's PR as `alice`, advance one cycle, then reopen T3's PR at day 8 and advance one cycle.

## Pass when

- T-GH-03 crash fixtures: inbound close/reopen receipt, transition, projections and keyed outbound intents commit atomically. A crash before commit leaves none; after commit recovery retains exactly one set. A crash after remote branch restoration or comment success reconciles the keyed effect before retrying and creates no duplicate effective write.

- Drive composed lifecycle jobs and the production stack delivery seam. Reclaim disk only after a retained final capture and no active terminal/service; absent capture retains it. Fixture seam coverage does not replace GitHub poll, reopen or built-in run-loop acceptance owned by their named tickets.

- After step 2: T2 is `dropped` with `state_reason` "closed on GitHub by @alice"; one `product_job_events` row carries Alice's GitHub actor; T3 has `rebase_pending`, and its next candidate no longer includes T2.
- After step 2, the write log has no Smithers write for T2 (no second close and no "Dropped in Smithers" comment).
- Step 3 adds no event and no state change.
- After step 4: T2 is `in_review` with one new event, back at its previous position between T1 and T3, its PR is followed again, and `smithers/<slug>` on the fake points at P2. No run is live, attempt 1 keeps outcome `dropped`, and g2 is the current generation with `candidate_verified`.
- Step 4a adds no event, attempt or run.
- After step 4b: one new attempt, attempt 2, on digest D, whose first message is Ben's comment. T2 passes `queued`, `starting` (left on `run_attached`) and `working`; its working copy holds `notes.txt` from the final capture; a new generation is accepted, and the PR head's tree equals its tree.
- After step 4c: exactly one merge call for T2, with `sha` = its PR head after the recheck, and T2 is `merged`.
- After step 5: T3 is `dropped` after the close and stays `dropped` after the day-8 reopen.

## Fail when
- The TODO shows `rejected`, `blocked` or `failed` instead of Dropped.
- The actor is missing or shows Smithers.
- A reopen within 7 days is ignored, lands at the end of the stack while its position is free, or one after 7 days restores the TODO.
- A repeated close produces a second transition.
- A review comment after a reopen reaches no run, starts two attempts, or starts one on a flow digest other than D.
- A duplicate reopen adds an event or an attempt.
