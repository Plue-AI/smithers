# C-J10-04 Unrelated merge on GitHub: `main` row updates; Rebase pending with people present, rebase without

Proves: mvp.md J10.4, §4.2 "Rebase", §6.3 "`main` moves" · spec.md §7.3, §9.4, §10.5.1–§10.5.3, §12.3 (`main` moved row) · Layer: e2e · Stage: S2 · Tickets: T-STK-11
Automation: `apps/app/e2e/real/github-j10/main-moved-rebase.spec.ts` (new) · Runs in: reference host

## Setup
- Reference host, stage 2 install at the commit under test, App installed on a fresh `smithers-mvp-canary/<date>`.
- Members: the owner, Ben (browser on a second Mac) and Alice (GitHub token).
- T5 In review on branch A with Ben's Branch card open, so Ben is present. T6 Working on branch B with only the coding agent present.
- An open PR on GitHub made by Alice outside Smithers that changes only `docs/unrelated.md`.

## Steps
1. Alice merges her PR on GitHub. Record t0 and the new `main` sha `M2`.
2. Watch the home card's `main` row.
3. Watch branches A and B for 5 min, with Ben still present on A.
4. Ben closes his tab. Wait for presence to expire (30 s).
5. Ben reopens branch A's card. Repeat steps 1–3 with a second unrelated PR, then Ben presses **Rebase now** on branch A.

## Pass when
- The `main` row shows `M2` and its title within 60 s of t0.
- Both T5 and T6 get `rebase_pending{onto: M2}`.
- Branch B rebases at its run's next durable boundary without anyone acting, posts a "Rebased onto main" activity entry, and its item change now descends from `M2`.
- Branch A shows "Rebase pending", and its head doesn't change while Ben is present (5 min).
- After step 4, branch A rebases within 60 s of presence expiry. After step 5, it rebases within 10 s of **Rebase now**.
- After each rebase of branch A, approvals for the old head are cleared, checks rerun, and its PR gets a new head whose parent is the new `main` tip under the same PR number.

## Fail when
- Branch A rebases while Ben is present and hasn't pressed **Rebase now**.
- Branch B waits for a person.
- The `main` row still shows the old sha more than 60 s after t0.
- A rebase leaves an approval on the new head.
