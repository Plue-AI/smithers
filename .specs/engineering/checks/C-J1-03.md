# C-J1-03 A question is answered with file cards before Machine ready

Proves: mvp.md J1.3, J1.5, §6.5 Answers, §3 (`main` has no machine) · spec.md §16.2 step 5, §8.6.3, §15.1, §11.5a, §7.6 (CodeFileView File card), §14.3 (File) · Layer: e2e · Stage: S1 · Tickets: T-INS-06, T-APP-15, T-REL-02
Automation: `apps/app/e2e/real/first-answer.spec.ts` (new) · Runs in: reference host

## Setup
- The install from C-J1-02 at the moment Source ready is shown, with the first image build still running. The build is held by T-INS-06's test hold so Machine ready cannot arrive during the check.
- Scratch repository `smithers-mvp-canary/<date>` whose `main` contains `src/mail/expiry.ts` with a function `sendExpiryEmail` on known lines.
- Signed in as the owner; the app agent's model is set by the owner (§11.5a), and the AI Gateway key is saved.

## Steps
1. Record `GET /api/install` (`source.state`, `machine.state`), `msb list` and `the runtime admission queue length`.
2. Press ⌘K and ask "where do we send the expiry email?".
3. Record the time of the first token and of the first file card render.
4. Open the file card maximized; hover `sendExpiryEmail`; press ⌘/Ctrl-click on it.
5. Repeat step 1.

## Pass when
- The answer arrives with at least one File card for `src/mail/expiry.ts` whose cited lines contain `sendExpiryEmail`, and the card's content equals `main` at the mirrored commit byte for byte.
- `machine.state` is not `ready` at the time of the first card render (both times recorded).
- Step 5 shows no new the runtime admission queue row and no VM other than the image build.
- The File card renders through existing CodeFileView, which T-APP-15 retains (§7.6). With no language server available, hover and definition bind no gesture: no error toast, no spinner, no dead click.
- First-token and full-answer times are recorded for C-PERF-01; they are not gated here.

## Fail when
- The chat answers "wait until the machine is ready", or the composer is disabled before Machine ready.
- The question wakes or queues a machine.
- The File card shows content from a working copy instead of the mirror, or never leaves a loading state.
- Hover shows an error or a refusal toast before Machine ready.
