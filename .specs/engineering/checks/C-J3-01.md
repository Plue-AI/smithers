Proves: mvp.md J3.2–J3.3, §6.8 Presence, M-17 · spec.md §2 (actor notation), §7.3, §7.6 (presence `{path, line}`), §8.10.4, §9.3.2, §14.3 (Branch), §14.6a · Layer: e2e · Stage: S2 · Tickets: T-COL-06, T-APP-10, T-REL-02

## Setup

- A fresh install at the commit under test on the reference host, reached at the owner-set public origin (§16.3). The scratch repository is `smithers-mvp-canary/<date>` with `retry.ts` (≥ 40 lines) and `deliver.ts`.
- Members:
  - Ben (owner) and Alice (member), each signed in with GitHub in their own browser context on a second Mac on the same network;
  - Maya (member), whose GitHub SSH key is on that Mac.
- TODO T2 "Retry webhooks" is `working` in its `implement` step on branch `smithers/retry-webhooks`, with the machine awake.
- Ben's home on the machine has Claude Code installed and signed in (his own login).

## Steps

1. Ben opens `/branch T2`. The presence list shows the coding agent with its step and the file the `agent` uid last wrote.
2. Alice opens `/file retry.ts` on the branch and moves to line 12. Ben's card shows Alice at `retry.ts:12`.
3. Maya runs `ssh -p 2222 retry-webhooks@<install host>`, edits `retry.ts` and saves. Ben's card shows "Maya via SSH" at `retry.ts`.
4. Ben opens `/terminal`. His row shows the terminal. Alice opens that terminal to watch, and her row shows "watching" Ben's terminal.
5. In his terminal Ben runs Claude Code through the Smithers skill and has it write `notes.md`. Inspect presence and the attributed activity entry; record its participant id, avatar and acting-for member. Also run a Smithers app-agent command and a reviewer step on this branch and inspect their participant heartbeats and resulting activity.
6. Alice opens a second tab on the same branch: still one Alice row.
7. Alice closes both tabs. Maya exits SSH.
8. Ben's browser loses network without closing (offline mode). From Alice's re-opened tab, record when Ben's row disappears.

## Pass when

- Each person or agent row appears with §14.6a rendering and its where: "Alice", "Maya via SSH", "Claude Code, for Ben", "Coding agent, for Ben", "Smithers, for Ben" and "Reviewer, for Ben". Each agent has its own avatar and participant id, distinct from Ben and other agents. Agent-authored activity uses the same participant id and acting-for member as presence. Rows appear within 1 s, p95 over the 12 measured actions in steps 2–5 repeated 10 times (n = 120); file coordinates use `{path, line}` (§7.6).
- One row per participant regardless of tab count. Agent session close removes its row even if Ben’s terminal remains open; an idle shell never keeps a finished agent participant present.
- Closed sockets and ended SSH sessions remove their rows within 1 s.
- A silent loss removes the row 30 s ± 1 s after its last heartbeat.
- `branch:<id>` deltas never exceed 4 per second during step 2's cursor movement.

## Fail when

- A row lingers after its actor left: past 31 s on silent loss, or past 1 s on a clean close.
- Maya's SSH session shows as "Maya", or as no one. Either means SSH presence is missing.
- The agent appears without a step or file.
- Two Alice rows appear, or Alice's where lags a move by more than 1 s.
- The card shows someone present because they once opened the branch (state not backed by a live heartbeat).
