# C-J9-01 Ask the repository: file and wiki cards; Make TODO and Save to wiki

Proves: mvp.md J9, §6.5, §6.11, Appendix A `/todo.new`, `/wiki.save` · spec.md §6.1 (three doors), §6.1.4, §6.2.1, §10.2, §13.1, §14.2, §14.5.1, §15.1.2, §15.1.5 · Layer: e2e · Stage: S1 · Tickets: T-APP-02
Automation: `apps/app/e2e/real/ask-repository.spec.ts` (new) · Runs in: reference host

## Setup
- Install at the commit under test with Source ready.
- Scratch repository `smithers-mvp-canary/<date>` whose `main` contains `src/webhooks/retry.ts` with `redeliver()`, and a wiki page "Webhooks" that names `redeliver`.
- Ben (member) signed in, in `main`'s conversation. Alice (member) watches the same conversation in a second browser.

## Steps
1. Press ⌘K and ask "where do we retry webhooks?".
2. Select **Make TODO** on the answer. Change the title in the Draft card, keep Append, press Commit twice quickly.
3. Select **Save to wiki** on the same answer.
4. Ask a second question ("what calls redeliver?"). Type "make that a TODO" in ⌘K, then type `/wiki.save` for the same answer.
5. Record `todos`, `todo_revisions`, `wiki_pages` and `wiki_page_revisions` rows created during the run.

## Pass when
- The first answer has a File card for `src/webhooks/retry.ts` whose cited lines contain `redeliver`, and a wiki card for "Webhooks".
- The answer offers Make TODO and Save to wiki.
- The Draft card opens prefilled with a title and a prompt that names `retry.ts`. Until Commit it is a private entry (`audience_member_id`, §14.5.1): Alice's browser shows neither the card nor its fields. After Commit it shows "Committed <edited title>", and exactly one new TODO exists, last in the stack, Queued, with revision 1 equal to the committed prompt.
- Save to wiki creates one page whose Markdown contains the answer text and the file reference, with one revision authored by Ben (or "Ben via Smithers" when the app agent wrote it, which happens only after Ben presses its one-click Confirm card, §15.1.5).
- Step 4's two doors produce the same results as the buttons: a Draft card and a page.
- The Home card shows the new TODOs without a reload.

## Fail when
- Two Commit presses create two TODOs (§6.2.1).
- The Draft card commits without the member pressing Commit, or the TODO appears on the stack before Commit.
- Save to wiki writes a page with no author, or one attributed to "Agent".
- A door answers with a usage sentence instead of a form card (§6.1.4).
