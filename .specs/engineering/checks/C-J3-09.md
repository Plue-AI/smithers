# C-J3-09 Hand-run `git checkout main` → Needs you; Return to Tn and Keep for now

Proves: mvp.md §6.8 External changes ("Maya moved this branch off T2 · Return to T2 · Keep for now"), M-14, M-27 · spec.md §4.1 (working → needs_you), §6.1.2 (`in-card`), §9.1.2 (`return_to_item`), §9.3.8, §10.8.2–10.8.3, §14.5.2 · Layer: e2e · Stage: S2 · Tickets: T-COL-05
Automation: `apps/app/e2e/real/branch-moved-off.spec.ts` (new) · Runs in: reference host

## Setup

- A fresh install at the commit under test, and the scratch repository `smithers-mvp-canary/<date>`. TODO T2 is `working` on `smithers/retry-webhooks` with uncommitted edits to `retry.ts` in its item change.
- Members: Ben (owner of T2) and Alice, both on the Branch card in their browsers. Maya has SSH.
- Before each move, record the item change id, `@`, `git rev-parse HEAD` and the SHA-256 of every tracked file.

## Steps

1. Maya runs `git checkout main` over SSH.
2. Observe Ben's and Alice's screens, the home card and the run trace for 30 s.
3. Ben and Alice press **Return to T2** within 100 ms of each other.
4. Repeat step 1. Maya then writes `notes.txt`, and Ben presses **Return to T2**.
5. Repeat step 1 with `jj new main`, then press **Return to T2**.
6. Negative cases, each followed by a 5 s wait: `git status`, `jj log`, a `git commit -am wip` on the item, `jj new` on top of `@`.
7. Repeat step 1 and Ben presses **Keep for now**. Wait 30 s. Maya then runs `jj edit <item change>`.

## Pass when

- After step 1, the TODO is Needs you within 1 s of the burst's activity entry, and the Branch card reads "Maya moved this branch off T2" with **Return to T2** and **Keep for now**.
- Ben (owner) and Alice (present) each get one toast whose action is Resolve → `/branch T2` (§14.5.2). The home card shows T2 in Needs you.
- While moved off, no write by the `agent` uid lands (checked in the `burst_files` rows), and every agent write attempt in the run trace is refused with `moved_off`.
- After step 3, exactly one Return applies, and the other gets "answered by" (§10.8.2).
  - `@`, `git rev-parse HEAD` and every tracked file's SHA-256 equal the record taken before step 1.
  - The TODO returns to `working`, and one activity entry names the person whose Return applied.
- After step 4, `notes.txt` is absent from `@` but present in its own commit in `jj log`, so it is recoverable.
- Step 5 behaves like steps 1–3, and the daemon log shows the metadata watch on `.jj/repo/op_heads/heads/` or `.git/HEAD` as the trigger (§9.3.3), not an activity burst.
- Step 6 raises nothing.
- After step 7's Keep for now, the TODO stays Needs you for the full 30 s and agent writes stay refused. After Maya's `jj edit`, the wait settles and the TODO returns to `working`.
- The item's captured head (`refs/smithers/branches/<id>/head`) never points at `main`'s commit at any time.

## Fail when

- The move goes unseen: no Needs you, or only a generic failure.
- Return leaves files from `main` in the working copy, leaves git `HEAD` on `main`, or loses the post-move write.
- Both Return presses apply, or the agent keeps writing while moved off.
- Keep for now settles the wait or lets the agent write while the working copy is still off the item.
- A read-only command (`git status`, `jj log`) raises Needs you.
- An Undo control appears on the card (per-entry Undo is [D], §9.3.5).
