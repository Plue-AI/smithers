# C-J8-03 Obsidian folder sync from Settings

Proves: mvp.md §6.11 Obsidian, J8 · spec.md §13.3 · Layer: e2e · Stage: S2 · Tickets: T-FLW-12
Automation: `apps/app/e2e/real/wiki-obsidian.spec.ts` (new) · Runs in: reference host

## Setup
An install with the wiki holding page `decisions/retry.md`, the owner signed in, and an empty folder `~/Vault` on the Mac.

## Steps
1. The owner sets `~/Vault` in Settings.
2. Wait one sync interval.
3. Edit `~/Vault/decisions/retry.md` on disk, adding one line.
4. Wait one sync interval and open the page in the app.
5. Edit the page in the app.

## Pass when
- After step 2, `~/Vault/decisions/retry.md` exists with its frontmatter.
- After step 4, the page shows the added line as a new revision attributed to the owner.
- After step 5, the folder file contains the app edit within one interval.
- A path inside the install's state directory is refused with a typed error.

## Fail when
- An import replaces the page wholesale and drops another edit.
- Attachments or frontmatter change bytes.
- The control is visible to non-owners.

## Evidence
`.artifacts/checks/C-J8-03/<ts>/`: folder snapshots before and after, the page revision list JSON, a Settings screenshot and the commit.
