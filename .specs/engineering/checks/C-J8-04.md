## Steps
1. Run T12's plan step.
2. Read the plan receipt (`PlanningContext.wikiCitations`) and the attempt evidence on `todo:12`.
3. Edit `retry-policy` to revision 4.
4. Read the receipt again. Retry T12 and read the new attempt's receipt.
5. Make `overview` stale by changing one of its inputs, then plan T13 with the same prompt.

## Pass when
- The receipt holds `{slug: "retry-policy", revision: 3, digest}` where `digest` equals SHA-256 of revision 3's stored Markdown.
- The selector ran with T12's prompt over wiki candidates only (§13.4), and every page in the planning context appears in `wikiCitations`, and every citation was in the context.
- The attempt evidence links each citation to that exact revision.
- After step 3 the first attempt's receipt still says revision 3; the retry's receipt says revision 4.
- T13's receipt doesn't cite the stale `overview`.

## Fail when
- Citations carry only `inputDigest` or the source revision, with no page revision (today's behavior).
- A citation's digest matches a different revision than its number.
- An earlier receipt changes when the page is edited later.
- `release-process` is cited without having entered the context.
