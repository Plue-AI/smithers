# C-J3-10 The coding agent's commands appear in a watchable Terminal card

Proves: mvp.md §11 stage 2 item 10, §3.1 · spec.md §7.5, §8.11.2a, §9.3.2 · Layer: e2e · Stage: S2 · Tickets: T-TRM-05
Automation: `apps/app/e2e/real/agent-terminal.spec.ts` (new) · Runs in: reference host

## Setup
A working TODO on a scratch repository whose test command is `pnpm test`, with Ben present on its branch.

## Steps
1. Ben opens the TODO's Branch card while the agent reaches its check step.
2. Ben opens the agent's terminal from the Branch card.
3. Ben types a character into it.
4. The run finishes the check step.

## Pass when
- The Branch card lists a terminal owned by "Agent" while the step runs.
- The card streams the exact `pnpm test` command and its output live (first output line visible within 1 s of the command starting).
- Ben's keystroke is dropped, and the drop counter increments.
- The run's tool result for that command equals the terminal output with ANSI stripped, plus the same exit status.

## Fail when
- The command runs with no terminal (output only in the transcript).
- A member can type into the agent's terminal.
- The tool result and the terminal disagree.
