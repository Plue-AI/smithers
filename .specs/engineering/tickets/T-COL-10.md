## Goal
Every interface that stage 3 co-editing depends on exists and is enforced from stage 1, so stage 3 adds a document layer without changing a stage-1 or stage-2 API.

## Scope

Topology-neutral (product, 16:58; smithers-22 and smithers-3f agreed): nothing here depends on T-COL-01's measurements. The ADR 0003 topology decision moved to T-COL-11, which T-COL-08 depends on.

In:
- `base_digest` and actor on every write to a branch's files, with `409 stale` on mismatch.
- Reserved live-channel topics (`doc:code:<branch>:<path>`, `doc:wiki:<page>`) and binary frame kinds 1–2. They are accepted and answered `unsupported` until stage 3.
- A contract test file that pins each §7.6 row.
- Before Wave A starts, fix daemon↔host framing in ADR 0004: numeric stream-kind discriminants (control, events, presence, reserved documents and sessions), byte order, lengths and bounds, request correlation, every §9.1.2 request/response and typed error, authenticated actor envelopes, seq/event_id, missing_objects and outbox ack. Define payload encoding and strict unknown-field refusal. Define the handshake: protocol version, boot id, relay secret and replacement of an older boot's connection. The boot id appears only in the handshake. No daemon↔host frame names a branch, machine or uid; the authenticated connection supplies that context. `open_session.user` is a login matching `[a-z0-9_-]{1,32}`. Define §9.6.2 session frames: data with stdout/stderr channel, eof, resize, signal, exit, window and close; each direction starts with 256 KiB credit. Define maximum frame size, the 1 MiB content limit (`MaxWorkspaceFileBytes`) and backpressure. Define event kinds: change, file_written hint, presence hint, needs_you and §9.6.6 transcript record. Only file_written and presence skip the outbox (§9.1.4). The S2 `unsupported` list is open_doc, close_doc and the document stream; capture flush is a no-op, not unsupported. The codec decodes reserved kinds in every stage; the handler refuses them in S2. Define S3 document sync, saved state vectors and epochs without changing reserved bytes. T-COL-03 no longer owns these schemas. Check: C-COL-01.

- smithers-38 ships the per-module TS document contract and a TS fake relay for T-APP-14a. The fake replays golden browser frames and actor/document envelopes from the same fixture set.

Out:

## Tests
- Integration (real PostgreSQL, microVM or process runtime): write with the correct `base_digest` succeeds. A concurrent write by a second actor makes the first actor's next write return 409 and leaves the file unchanged.
- Integration: a write without `base_digest` returns 400. A write with `base_digest: "absent"` creates a missing file and refuses an existing file. Read and write responses carry the correct digest. Bodies sending actor, branch, machine or uid return 400; actor uses the authenticated principal plus `via`. Check: C-COL-01.
- Unit: the live channel answers a subscription to `doc:code:b:p` with `unsupported` and keeps the connection open.
- Contract test: OpenAPI matches digest/"absent" requests, digest-bearing read and write responses, server-derived actor plus `via`, forbidden body fields and tagged 409. Check: C-COL-01.
- Golden-frame tests: encode/decode literal requests, responses, errors, reserved kinds, events, acknowledgements and document envelopes in Go, Rust and TS. Cover missing_objects, duplicate receipts and reconnect order. Add refusal vectors for an unknown field (`uid`), an envelope naming a branch, and one per error kind: truncated, oversized, unknown kind, reserved-in-S2 and trailing bytes. Each refusal is a typed error. The codec decodes reserved kinds in every stage; the reserved-in-S2 vector proves the handler returns typed `unsupported`, not a stage-conditional decode failure. The same bytes are accepted by the S3 handler. Check: C-COL-01.
- TS fake relay replays golden sync/awareness/saved/epoch/backpressure frames exactly. T-COL-03r’s Rust fake host and T-COL-03f’s Go fake daemon must pass identical applicable vectors before component results count. Real codecs must pass the same fixtures before integration.
- Honest state (C-UI-05 row): a refused stale write shows as refused in the card, never as saved.
- Version contract (smithers-38, required): the Rust test asserts the crate's resolved `yrs` version equals MANIFEST.json's, and the rpc test asserts the installed `yjs` version equals MANIFEST.json's, so bumping either side fails the contract until the frames are regenerated.
