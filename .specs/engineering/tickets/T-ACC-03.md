## Goal
Every served `/api` command is authorized by `Authorize(credential, command, subject)` from the literal catalog descriptors (§5.2.1), including actor eligibility, minimum role, credential scope and agent policy. Eligible person-only delegated commands return 403 never/never; excluded trusted classes on multi-actor rows and scope/role failures return 403 permission/permission; eligible confirmable commands create a confirmation through T-APP-04 and return 202 with its id. Checks: C-ACC-01, C-ACC-02.
