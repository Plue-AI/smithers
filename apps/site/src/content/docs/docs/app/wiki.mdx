Use **Wiki** to read and edit the notes Smithers keeps about the project.

## Open a note

1. Select **Wiki** in the sidebar.
2. Select a note from the list.
3. Read the note and its source and confidence information.

<AppScreenshot src="/images/app/wiki.png" alt="The Wiki pane shows a World note, its source count, and its confidence label beside the chat." caption="Wiki opens beside the conversation, so you can ask about a note while reading it." />

Use **Back to the conversation** to close the pane. A note's confidence label is recorded metadata; check the source when a statement matters to your work.

## Add or edit a note

Select **New note** to create a note, then write in the editor. To revise an existing note, select it and edit its content. Keep facts and their sources together so another reader can check the claim.

Editing a note is distinct from landing a code change. Review code through the [Change card](/docs/app/changes/).

## Read the repository's guide files

Use `/files.read README.md` or `/files.read CONTRIBUTING.md` to read the selected repository's guide files in the conversation.

A starter note named **World** is not evidence that the repository has a generated wiki.

## Generate or browse repository pages

Use `/wiki.create owner/repo` to request generation in the background and `/wiki.cloud owner/repo` to browse published pages when the host enables the Wiki service. Follow the generation run to completion; opening the Wiki or accepting the request does not mean pages have been published.

The app's current generator creates a source index of tracked paths at a named revision. The separate engineering recipe reviews explanations against citations, but that reviewed output is not yet the app generator's output. Automatic refresh after a landed change is still tracked in [#1923](https://github.com/smithersai/smithers/issues/1923). Check a page's source revision before treating it as current.

## Inspect the factory

Select **Factory** in the Wiki pane to inspect the repository's wiki information and available environment configuration files. This is a way to read the factory's configuration. It does not create a box or regenerate the wiki.
