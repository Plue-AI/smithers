The app is one conversation. The repository selector sets its context. Press Command-K (Ctrl-K on Windows and Linux) to open **Chat**. Results arrive as cards: files, runs, approvals, changes.

## The sidebar

| Area | For |
| --- | --- |
| [Inbox](/docs/learn/approvals/) | Approvals and questions waiting for you. |
| [Conversations](/docs/learn/chat/) | Your chats and the repository's issues. |
| [Agents](/docs/learn/watch-an-agent/) | Each agent and its runs. |
| [Wiki](/docs/learn/wiki/) | Notes about the project. |
| [Dispatcher](/docs/learn/agent-and-trigger/#put-it-on-a-schedule) | Rules and schedules. |
| [Flows](/docs/learn/run-a-flow/) | The repository's flows and their runs. |
| [Secrets](/docs/learn/secrets/) | Secret names and where they apply. |
| [History](/docs/learn/issue-to-main/) | Each issue's path to main. |
| [Account](/docs/learn/account/) | Your GitHub account. |

Your [boxes](/docs/learn/boxes/) and their files sit under the repository.

Wiki and Flows open beside the conversation; **Back to the conversation** closes them. **Maximize card** gives a card more room.

## Ask, click, or type

Every action works three ways: ask for it, select it on a card, or type its command. Type `/` to browse commands; a trailing dot, such as `/review.`, lists a group. A command that needs input opens a form.

Signed out, you can read a public repository's home, guide files, and rules. Everything else asks you to [sign in](/docs/learn/account/).
