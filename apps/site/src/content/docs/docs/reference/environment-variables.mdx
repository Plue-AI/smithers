title: "Environment variables"

These variables configure the CLI's control, cache, and provider integrations. An empty control-plane setting reads like an unset value. Individual build rules and external tools can read additional variables declared by their own contracts.

## Operator variables

Variables an operator exports to steer the CLI.

| Name | Set by | Purpose | CLI flag equivalent |
| --- | --- | --- | --- |
| `SMITHERS_AUDIENCE` | operator | Presentation audience: `auto`, `human`, or `agent`; does not change authority. | `--audience` |
| `SMITHERS_CREDENTIAL_KEY` | operator | Base64-encoded 32-byte host key for encrypting stored credentials. Keep it separate from the database. | none |
| `SMITHERS_CACHE_URL` | operator | Remote target-cache endpoint. | none |
| `SMITHERS_CACHE_TOKEN` | operator | Remote target-cache credential. | none |
| `SMITHERS_CACHE_NAMESPACE` | operator | Trust domain used when publishing target-cache results. | none |
| `SMITHERS_REMOTE` | operator | Control-plane base URL. | `--remote` |
| `SMITHERS_TOKEN` | operator | Preferred bearer credential channel for the remote control plane; avoids argv exposure. | `auth login` |
| `SMITHERS_MCP_CONFIG` | operator | Path to the MCP server array the local executor projects into a run's flow catalog. | `--mcp-config` |
| `SMITHERS_OPENAI_AUTH` | operator | `api-key` or `chatgpt`, selecting how `openai` seats authenticate. For local seats, `chatgpt` opts into the Codex subscription and runs the vendor CLI after `codex login status` confirms a ChatGPT login; Smithers never reads its credential store. Any other value refuses the seat. | none |
| `SMITHERS_BACKEND` | operator | Database backend: `sqlite` or `postgres`. Any other value exits 1 with `unsupported_database`. | `--backend` (hidden) |
| `SMITHERS_POSTGRES_URL` | operator | PostgreSQL connection string; selects PostgreSQL (`DATABASE_URL` counts only with `SMITHERS_BACKEND=postgres`). | none |
| `SMITHERS_BUG_ENDPOINT` | operator | Where `smthrs bug` posts its report. | none |
| `SMITHERS_JJ_PATH` | operator | Explicit path to the `jj` binary. | none |
| `SMITHERS_WORKSPACE_JJ_EXPORT_BINARY` | operator | Absolute path to the `smithers-jj-export` filesystem helper, when it is not in a searched location. | none |
| `SMITHERS_MEMORY_DB` | operator | Moves the memory store to its own SQLite file, shared by runs of one repository in separate workspaces. | none |
| `SMITHERS_MODEL_PROXY_URL` | operator | Base URL of a model proxy that fronts the provider routes. | none |
| `SMITHERS_ACCOUNT_POOL_URL` | operator | Smithers account pool of connected ChatGPT sign-ins and Anthropic API keys that signs `openai:` and `anthropic:` seats; with `SMITHERS_ACCOUNT_POOL_KEY` and `SMITHERS_ACCOUNT_POOL_PROVIDERS`. | none |
| `SMITHERS_TUI_BIN` | operator | The executable `smthrs tui` runs. See [TUI configuration](/docs/tui/configuration/) for chat, worker, approval, budget, and conversation settings. | none |
| `SMITHERS_DETACHED_ADMISSION_TIMEOUT_MS` | operator | How long a detached flow launch waits for the detached run's admission line. A value that is not a positive integer is ignored. | none |
| `SMITHERS_TEST_COMMAND` | operator | The command the `test` flow runs. | none |
| `SMITHERS_TEST_CONTAINER` | operator | The container the `test` flow runs in. | none |
| `SMITHERS_TEST_CWD` | operator | The repository's path inside that container. | none |
| `SMITHERS_TEST_TIMEOUT_MS` | operator | Wall-clock budget for one `test` invocation. | none |
| `SMITHERS_SANDBOX_IMAGE` | operator | The image a flow's `sandbox: {provider: container}` runs in, through `docker`, with the flow's network and limits. Unset refuses such flows; they never run on the host. | none |
| `SMITHERS_BASH_CONTAINER` | operator | The one container `bash` may reach. Any other `bash` call, including one naming no container, fails with `outside_container`, and the host filesystem flows are not offered. | none |

## HTTP proxies

The native Node control host's model HTTP transport reads `http_proxy`,
`https_proxy`, and `no_proxy`, falling back to `HTTP_PROXY`, `HTTPS_PROXY`, and
`NO_PROXY`. Lowercase values take precedence even when empty. `no_proxy`
selects destinations that bypass the proxy. If both proxy URLs are unset or
empty, the dispatcher connects directly. Rebuilt connection pools use the
same policy.

## Provider keys

A Claude subscription runs only as a `claude-code:*` seat on your own Claude Code, signed in with `claude auth login`; Smithers never reads, stores, or forwards a Claude subscription token. Flow judgments use a connected ChatGPT subscription, directly or through the account pool. Gateway and provider keys cannot substitute for a subscription. `smthrs doctor` reports available model connections.

| Name | Read by | Purpose |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | seat resolver | Credentials for `anthropic:*` seats. Without it, a Claude alias (`opus`, `fable`) runs as its `claude-code:*` seat. |
| `CODEX_HOME` | seat resolver | Codex account directory for the ChatGPT subscription. |
| `SMITHERS_ACCOUNT_POOL_URL`, `SMITHERS_ACCOUNT_POOL_KEY` | seat resolver | Account-pool connection and host credential. |
| `OPENROUTER_API_KEY` | seat resolver | Credentials `openrouter:*` seats. |
| `CEREBRAS_API_KEY` | seat resolver | Credentials for `cerebras:*` seats. |
| `MOONSHOT_API_KEY` | seat resolver | Credentials for `moonshot:*` seats. |
| `GEMINI_API_KEY` | seat resolver | First credential source for `gemini:*` seats. |
| `GOOGLE_API_KEY` | seat resolver | Fallback for `gemini:*` seats when `GEMINI_API_KEY` is unset or empty. |

## Removed in 1.0

`SMITHERS_HOME`, `SMITHERS_TOKEN`, and the `SMITHERS_WORKFLOW_*` family are gone: `~/.smithers` is not a runtime input, and `SMITHERS_TOKEN` belongs to a different product's CLI. See [the 1.0 migration guide](/docs/migration/1.0/).
