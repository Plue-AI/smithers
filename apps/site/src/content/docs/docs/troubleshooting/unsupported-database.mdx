## unsupported_database

```text
unsupported_database: choose sqlite or postgres. PostgreSQL requires SMITHERS_POSTGRES_URL or DATABASE_URL. See https://smithers.sh/migration/1.0#databases.
```

**Cause.** `SMITHERS_BACKEND` or `--backend` names a backend other than `sqlite` or `postgres`, such as `pglite`. The command exits 1 rather than run your flows against a database you did not ask for.

**Fix.** Unset `SMITHERS_BACKEND`, or set it to `sqlite` or `postgres`. PostgreSQL also needs `SMITHERS_POSTGRES_URL` or `DATABASE_URL`:

```bash
unset SMITHERS_BACKEND
export SMITHERS_BACKEND=sqlite
```

A one-line stderr notice, not a refusal, fires for a 0.x setting that is still exported (`SMITHERS_TEST_PG_URL`, or a `SMITHERS_POSTGRES_*` name other than `SMITHERS_POSTGRES_URL` and `SMITHERS_POSTGRES_SCHEMA`):

<pre><code>ignored: SMITHERS_POSTGRES_POOL_MAX has no effect in {versions.cli} (use SMITHERS_POSTGRES_URL to select PostgreSQL)</code></pre>

**Verify.** The command proceeds past backend selection.
