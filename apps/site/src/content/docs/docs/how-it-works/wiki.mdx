The **wiki** is what people and agents know about the project. Both read it and write it. Agents read it before they plan.

## Versioned

**Available now.** Every edit is a new revision; earlier revisions are kept. An edit names the revision it started from, so two editors cannot silently overwrite each other.

## Tied to sources

**Available now.** Generated pages say which code they describe. Open **Wiki** in the app to read and edit notes, or run `/wiki.create owner/repo` to generate pages from the repository.

## Kept current

When a change lands, Smithers regenerates the pages it affects, reviews each against the code, and publishes it. Pages a person edited stay as written.

**Partly available.** The refresh after each landing is rolling out ([#1923](https://github.com/smithersai/smithers/issues/1923)). Check a page's source revision before relying on it.

## Public and private

**Planned.** A public and a private wiki per repository. The private one is for members only.

## Sync with knowledge tools

**Planned.** Two-way sync with Notion, and with a local Markdown folder.
