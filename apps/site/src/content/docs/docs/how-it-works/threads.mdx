A **thread** is a conversation that lasts: a subject, an ordered list of messages, and the people and agents taking part. Work starts in a thread and reports back to it.

| Kind | What it is for |
| --- | --- |
| Issue | Something to track until it is done, visible to the repository's team. |
| Chat | A private conversation with Smithers and your agents. |

A chat is an issue too: a private one, visible only to you. A message is a comment. So chats get what issues get: history, search in your own threads, and sync.

## Issues

**Available now.** An issue has a title, a state, labels, assignees, and comments. Every change is recorded as an event.

The list shows the repository's Smithers issues with its GitHub issues. GitHub issues are read into Smithers.

## Chats

**Available now.** [Chat](/docs/learn/chat/) with Smithers in the app or the TUI. The app keeps your conversation for your account; the TUI keeps sessions in the project.

**Planned.** Chats stored as private issues, with agents replying under their own names ([#2111](https://github.com/smithersai/smithers/issues/2111)).

## Messages start work

A message in a thread can trigger a flow. The assistant answers, or hands the request to the right [agent](/docs/how-it-works/agents/) and posts its reply in the same thread.

**Planned.** Message triggers for chat threads. See [Triggers and flows](/docs/how-it-works/triggers-and-flows/).

## Sync with Slack and Telegram

A thread can mirror into one Slack thread or Telegram chat. Sync is two-way: a message, edit, or delete on either side appears once on the other. Agents post under their own names.

**Planned.** Thread sync set up from the app ([#2105](https://github.com/smithersai/smithers/issues/2105)). Telegram reactions are not mirrored ([#2110](https://github.com/smithersai/smithers/issues/2110)). See [Mirror a thread](/docs/learn/mirror-a-thread/).
