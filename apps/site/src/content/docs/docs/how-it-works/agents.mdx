An **agent** in Smithers is a **profile**, and a profile is a flow: a `flows/<id>/flow.mdx` file in your repository. The front matter says which model runs it, what it may touch, and how much it may spend. The body is its charter.

## A profile

**Available now.**

```markdown title="flows/reviewer/flow.mdx"
---
description: Reviews a change and returns a verdict with reasons.
model: openai:gpt-6-sol
capabilities: ["fs:read:**", "proc:spawn:*"]
budget:
  tokens: 200000
  milliseconds: 600000
---

# Review the change

Read the diff. Run the tests. Return approve or request changes,
with the evidence for each finding.
```

| Part | What it decides |
| --- | --- |
| `description` | One line shown wherever the profile is listed. |
| `model` | The model seat, such as `openai:gpt-6-sol`. |
| `capabilities` | What it may touch. Anything not granted is refused. |
| `budget` | The most tokens and time one run may spend. |
| `flows` | Other flows it may call, such as a specialist. |
| Body | The charter: the job, the output, and when to stop and ask. |

Skills are `SKILL.md` files beside your flows. A skill adds instructions, never permissions. [flow.mdx frontmatter](/docs/reference/flow-mdx/) lists every key.

## Agents call agents

**Available now.** A profile lists the flows it may call under `flows`. A called flow runs as a child run, with its own model, grants, and timeline. A child can only narrow what its parent may touch.

## See what an agent did

**Available now.** A profile's runs are the runs of its flow. Filter the run list by flow to see one agent's history, then open a run's timeline. See [Watch an agent work](/docs/learn/watch-an-agent/).

**Planned.** An Agents list in the app showing every configured profile, who it reports to, and a **Runs** button ([#2113](https://github.com/smithersai/smithers/issues/2113)).

## Guards

**Available now.** `budget` bounds a run's tokens and time.

**Planned.** When a run hits its budget or time limit, it parks and asks you to continue or stop, in the thread and the inbox ([#2114](https://github.com/smithersai/smithers/issues/2114)).

## Memory

**Planned.** Each run starts with the memories relevant to its thread, from banks its capabilities grant. See [Memory](/docs/concepts/memory/) for the store underneath.
