Start with the error on the card, row, or output. It names what failed and what to do next.

## Find the error

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Read the card or notification. Open the run card for its status, output, and any waiting approval.

| You see | Do |
| --- | --- |
| A sign-in prompt | Sign in; if asked, select **Request access** and wait for approval. |
| No flows or boxes | Check the selected repository, then [open a box](/docs/learn/boxes/). |
| A notification over a control | Select **Dismiss**, then retry. |
| An unknown slash command | Type `/` and pick from the menu. |
| An empty Wiki or History | [Generate the wiki](/docs/learn/wiki/) or [turn on the stack](/docs/learn/issue-to-main/). |
| A waiting or failed run | [Answer its approval](/docs/learn/approvals/), or fix the error and retry. |

</TabItem>
<TabItem label="TUI">

**Available now.** Ctrl+O expands a row's error; `/session` shows the log path.

| You see | Do |
| --- | --- |
| No model available | Set a provider key and restart. See [Configuration](/docs/tui/configuration/). |
| Worker parked | Wait for its reset, or press `m` for another model. |
| Worker failed | Press `r` to retry. |
| `Stop running work first` | Stop or finish running work before switching conversations or undoing. |
| Undo refused | The file changed since; review the newer edit. |
| Flow runs old code | Restart the TUI after changing a `flow.ts`. |
| Input form gone | Open the flow's tab and press `a`. |
| `y` types a letter | Empty the editor and wait for the approval keys. |
| Monitor refused | Set `AI_GATEWAY_API_KEY`. |

<AppScreenshot src="/images/learn/tui-provider-failure.gif" alt="A provider refusal in the TUI with its error expanded." caption="The TUI with a refusing test provider." width={880} height={480} />

</TabItem>
<TabItem label="CLI">

**Available now.**

```sh
smthrs doctor
smthrs info
```

`doctor` checks flow discovery, providers, tools, and stored state. `info` reports the workspace and host.

</TabItem>
<TabItem label="API">

**Available now.** An error response carries `code` and `message`, and an `X-Request-Id` header. `retry_after` or `Retry-After` says when to retry.

</TabItem>
</Tabs>

## Report a problem

Check [Smithers status](https://status.smithers.sh). Then open an issue in the [Smithers repository](https://github.com/smithersai/smithers/issues) with what you did, the error, the repository, and the run ID. Remove credentials and private code first.

<Tabs syncKey="surface">
<TabItem label="GUI">

Include a screenshot with private details removed.

</TabItem>
<TabItem label="TUI">

Include the command, runtime version, and a redacted excerpt of the conversation log.

</TabItem>
<TabItem label="CLI">

**Available now.** Submit a redacted report:

```sh
smthrs bug "flow start hangs after approval" --dry-run
```

</TabItem>
<TabItem label="API">

Include the request, status, response body, and `X-Request-Id`, without the token.

</TabItem>
</Tabs>
