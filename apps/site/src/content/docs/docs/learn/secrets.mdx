Everything that runs in a repository's boxes may use its secrets. Values are never shown. Never paste a secret into chat.

## See the list

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Select **Secrets** in the sidebar. Each row shows the name, the hosts it is bound to, the header it sets, and when it changed.

</TabItem>
<TabItem label="TUI">

The TUI reads secrets from your local environment. See [Configuration](/docs/tui/configuration/).

</TabItem>
<TabItem label="CLI">

**Available now.**

```sh
smithers secret list --repo acme/app
```

</TabItem>
<TabItem label="API">

**Available now.** `GET /api/repos/{owner}/{repo}/secrets`, with write permission.

</TabItem>
</Tabs>

## Add or remove one

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now**, admin only. On the Secrets card, **Add secret** opens a form: the name, the value, and optionally the hosts and header it is bound to. **Rotate** replaces a value and keeps its binding; **Delete** removes it. The value field is masked, and the app never shows or keeps a saved value.

`/secrets.set API_TOKEN` and `/secrets.delete API_TOKEN` do the same from chat.

</TabItem>
<TabItem label="TUI">

Set the variable in your shell before starting the TUI.

</TabItem>
<TabItem label="CLI">

**Available now.**

```sh
smithers secret set NAME --repo acme/app --body-stdin < secret.txt
smithers secret delete NAME --repo acme/app
```

</TabItem>
<TabItem label="API">

**Available now**, admin only. `POST /api/repos/{owner}/{repo}/secrets` adds one; `DELETE /api/repos/{owner}/{repo}/secrets/{name}` removes it. The app's secrets are `PUT` and `DELETE /api/repos/{owner}/{repo}/agent-environment/secrets/{name}`; `PUT` takes `value`, `hosts` and `match_headers` and answers metadata only.

</TabItem>
</Tabs>

## Keep a secret to main

A main-only repository secret reaches only a trusted run on the default bookmark: a person's push to it, a schedule, or a person's dispatch of it. Agent runs and runs of other branches, landings, and pull requests never receive it. Replacing its value keeps the mark.

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** `/secrets.scope DEPLOY_TOKEN main-only`; `all` gives it to every run again.

</TabItem>
<TabItem label="TUI">

Use the CLI or the API.

</TabItem>
<TabItem label="CLI">

**Available now**, admin only:

```sh
printf %s "$TOKEN" | smithers secret set DEPLOY_TOKEN --body-stdin --main-only
smithers secret scope DEPLOY_TOKEN all
```

</TabItem>
<TabItem label="API">

**Available now**, admin only. `"main_only": true` in `POST /api/repos/{owner}/{repo}/secrets`, or `PATCH /api/repos/{owner}/{repo}/secrets/{name}` with `{"main_only": true}`. The list shows `main_only`.

</TabItem>
</Tabs>
