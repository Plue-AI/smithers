Every session in a repository may use its secrets. Values are never shown. Never paste a secret into chat.

## See the list

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Select **Secrets** in the sidebar. Each row shows the name, the hosts it is bound to, the header it sets, and when it changed.

</TabItem>
<TabItem label="TUI">

The TUI reads secrets from your local environment. See [Configuration](/docs/tui/configuration/).

</TabItem>
<TabItem label="CLI">

**Available now** for local credentials, stored encrypted in the project:

```sh
smthrs credentials list
```

</TabItem>
<TabItem label="API">

**Available now.** `GET /api/repos/{owner}/{repo}/secrets`, with write permission.

</TabItem>
</Tabs>

## Add or remove one

<Tabs syncKey="surface">
<TabItem label="GUI">

**Planned.** Adding and removing secrets in the app. Ask a repository admin to use the API meanwhile.

</TabItem>
<TabItem label="TUI">

Set the variable in your shell before starting the TUI.

</TabItem>
<TabItem label="CLI">

**Available now** for local credentials:

```sh
export SMITHERS_CREDENTIAL_KEY=<your key>
smthrs credentials add github --name "GitHub" --secret-env GITHUB_TOKEN
smthrs credentials revoke github
```

</TabItem>
<TabItem label="API">

**Available now**, admin only. `POST /api/repos/{owner}/{repo}/secrets` adds one; `DELETE /api/repos/{owner}/{repo}/secrets/{name}` removes it.

</TabItem>
</Tabs>
