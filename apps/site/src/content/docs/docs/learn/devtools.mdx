A run is a tree of nodes: the run, each of its turns, the cells a turn ran, the flows a cell called, and the executions the engine recorded. DevTools shows that tree beside one node's evidence and keeps both current while the run is live.

Every surface reads one projection over the run's journal (`@smthrs/gateway` `RunDevTools`), so the tree the app draws is the tree the terminal and the CLI print.

## What a node shows

| Fact | Where it comes from |
| --- | --- |
| State | The node's status word: running, waiting, completed, failed, denied, or the engine's `recorded`. |
| Timing | When it started and how long it ran; an open node is measured to the newest record. |
| Input and output | A call's journaled input and settled value; a model turn's text; a cell's script and what it printed. |
| Failure | The message the settlement carried. |
| Fields | Every other field of the record that opened the node. |
| Frames | The journal records written while the node was open, newest last. The run itself owns the whole journal. |

Nothing is inferred. A fact the journal did not record is absent.

## Open DevTools

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Open the run's card and select **DevTools** in the timeline bar, or enter `/runs.trace.view <run> devtools`. Select a node to inspect it; select it again to return to the run. The pane follows the newest turn until you select a node, and it keeps updating from the run's subscription either way. Select **Timeline** to return.

</TabItem>
<TabItem label="TUI">

**Available now.** `/devtools` prints this conversation's run. `/devtools <tab>` prints a flow tab's run, and `/devtools <tab> <node>` inspects one of its nodes by the id the tree shows.

</TabItem>
<TabItem label="CLI">

**Available now.**

```sh
smthrs runs devtools <run>
smthrs runs devtools <run> <node>
smthrs runs devtools <run> <node> --frames 20 --json
```

The tree comes first, the selected node marked with `>`, then the node's facts. `--json` prints the projection: `nodes`, `counts`, `wallMs` and `inspection`.

</TabItem>
<TabItem label="API">

**Available now.** `Projection.Snapshot` or `Projection.Subscribe` with selector `run-events` returns the journal; fold it with `RunTrace.traceFromJournal` and read `RunDevTools.devTools(model)` for the tree and `RunDevTools.inspect(model, nodeId)` for one node. MCP: `runs_devtools`.

</TabItem>
</Tabs>
