You can browse a public repository signed out. Sign in with GitHub to chat about your work, run flows, and use a box. To work on your own repository, [register it](/docs/learn/open-a-repository/#register-your-repository); we review it.

## Sign in

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Select **Sign in with GitHub**, review the permissions, and return to Smithers.

<AppScreenshot src="/images/app/account.png" alt="Signed out, Account answers in the conversation with a Sign in with GitHub button." caption="Account, signed out." width={852} height={92} />

</TabItem>
<TabItem label="TUI">

The TUI uses your local model provider keys, not a Smithers account. See [Configuration](/docs/tui/configuration/).

</TabItem>
<TabItem label="CLI">

**Available now.**

```sh
smithers config set api_origin https://your-api-host
smithers auth login
```

</TabItem>
<TabItem label="API">

**Available now.** Send a personal access token: `Authorization: Bearer <token>`. `GET /api/user` returns the signed-in account.

</TabItem>
</Tabs>

## Check your account

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Select **Account**. It shows your GitHub account, its access, its scopes, and your boxes. `/billing.plans` shows your plan; see [Pricing](/docs/pricing/).

</TabItem>
<TabItem label="TUI">

Not applicable.

</TabItem>
<TabItem label="CLI">

**Available now.**

```sh
smithers auth status
smithers auth logout
```

</TabItem>
<TabItem label="API">

**Available now.** `GET /api/user`.

</TabItem>
</Tabs>

## Sign out

Select **Sign out** on the Account card.
