The wiki holds what people and agents know about the project. Every edit is a revision.

## Read and edit

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.**

1. Select **Wiki** in the sidebar and choose a note. Its source and confidence are shown above it.
2. Edit it in place, or select **New note**. Keep each fact with its source.
3. Select **Back to the conversation** to close the pane.

**Factory** in the pane lists the repository's wiki and environment files.

<TabItem label="API">

**Available now** where the host enables the Wiki service.

```sh
curl "$SMITHERS_API/api/repos/acme/app/wiki" -H "Authorization: Bearer $SMITHERS_TOKEN"
curl "$SMITHERS_API/api/repos/acme/app/wiki/getting-started" -H "Authorization: Bearer $SMITHERS_TOKEN"
curl -X PATCH "$SMITHERS_API/api/repos/acme/app/wiki/getting-started" \
  -H "Authorization: Bearer $SMITHERS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"expected_revision":3,"body":"# Getting started\n\nRun pnpm install."}'
```

`expected_revision` refuses the edit if someone saved first. `GET .../wiki/{slug}/revisions` lists history.

</TabItem>

## Generate pages from the code

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Enter `/wiki.create owner/repo`. Smithers writes the pages declared in `.smithers/coding-project.json`, in the background. `/wiki.cloud owner/repo` browses the published pages. The repository needs its [stack](/docs/learn/issue-to-main/) turned on.

</TabItem>
<TabItem label="TUI">

**Planned** ([#2119](https://github.com/smithersai/smithers/issues/2119)).

</TabItem>
<TabItem label="CLI">

**Planned** ([#1989](https://github.com/smithersai/smithers/issues/1989)).

</TabItem>
<TabItem label="API">

**Available now.** `POST /api/repos/{owner}/{repo}/mythical/wiki` requests a refresh and answers `202`. It answers `409` if the stack is off or the repository declares no wiki.

</TabItem>
</Tabs>

## Kept current

**Partly available.** When main moves, Smithers regenerates the declared pages, reviews them against the code, and keeps pages a person edited. Hosted proof is tracked in [#1923](https://github.com/smithersai/smithers/issues/1923).

**Planned.** A private wiki beside the public one, and two-way sync with Notion or a Markdown folder.
