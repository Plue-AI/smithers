Search when you know what you want but not where it is.

## Find anything

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Press Command-K (Ctrl-K on Windows and Linux) and type a name. Type `?` to see the prefixes.

| Prefix | Finds |
| --- | --- |
| none | Everything, by name |
| `/` | Flows and commands |
| `//` | Build targets |
| `wiki:` | Wiki pages |
| `run:` | Runs |
| `change:` | Changes |
| `#` | Issues |
| `box:` | Boxes |
| `secret:` | Secret names |

<AppScreenshot src="/images/app/search.png" alt="The search palette listing its prefixes after typing a question mark." caption="Search prefixes." width={852} height={600} />

</TabItem>
<TabItem label="TUI">

**Available now.** Press Ctrl+K. Type `@` in the composer to mention a file.

| Input | Finds | Enter |
| --- | --- | --- |
| `math` | Commands and file paths | Runs it, or inserts `@path` |
| `/` | Commands | Runs it |
| `text:add` | Text in files | Inserts `@path:line` |
| `conversation:review` | Saved conversations | Resumes it |
| `tab:review` | Background workers | Opens it |

<AppScreenshot src="/images/learn/tui-text-search.gif" alt="Searching file contents from the TUI and inserting the match." caption="The TUI with a scripted test model." width={880} height={480} />

</TabItem>
<TabItem label="CLI">

**Planned** ([#1989](https://github.com/smithersai/smithers/issues/1989)).

</TabItem>
<TabItem label="API">

**Partly available.** `GET /api/search/issues`, `/code`, `/repositories`, and `/users`, where the host enables search. `GET /api/repos/{owner}/{repo}/wiki/search?q=` searches the wiki.

</TabItem>
</Tabs>
