A repository gives your conversation its context: files, flows, issues, and wiki.

## Open one

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** On [smithers.sh](https://smithers.sh), pick a repository and select **Open Smithers**. Its home shows the description and featured flows. With several repositories, switch with the selector beside the message box.

</TabItem>
<TabItem label="TUI">

**Available now.** Start it in the checkout: `smthrs tui /path/to/repo`.

</TabItem>
<TabItem label="CLI">

**Available now.** From a checkout, open it in the app:

```sh
smthrs open
```

It opens the desktop app when installed, otherwise prints the `https://smithers.sh/<owner>/<repo>` link.

</TabItem>
<TabItem label="API">

**Available now.** `GET /api/repos/{owner}/{repo}`; `GET /api/user/repos` lists yours.

</TabItem>
</Tabs>

## Read its guide files

<Tabs syncKey="surface">
<TabItem label="GUI">

**Available now.** Enter `/files.read README.md` or `/files.read CONTRIBUTING.md`. Select **Maximize card** for more room.

<AppScreenshot src="/images/app/file.png" alt="CONTRIBUTING.md open in a file card." caption="A file card." width={852} height={664} />

</TabItem>
<TabItem label="TUI">

**Available now.** Ask for it, or type `@README.md` to add it to your message.

</TabItem>
<TabItem label="CLI">

Read the files in your checkout.

</TabItem>
<TabItem label="API">

**Available now.** `GET /api/repos/{owner}/{repo}/file/{change_id}/{path}`.

</TabItem>
</Tabs>

## Register your repository

Register a repository; we review it. You can register one at a time.

Paste the repository's link. Smithers analyzes it while you watch, answering each question itself, and gives you a report: license, how checks run, contributors, agent readiness, and chores worth automating. The report is yours to keep. Then we review the registration and set Smithers up.

<Tabs syncKey="surface">
<TabItem label="GUI">

**Planned.** Sign in with GitHub on [smithers.sh](https://smithers.sh/smithersai/smithers), then select **Register a repository** on [the home page](https://smithers.sh/?register=1), or enter `/repository.register`. Paste the link. Smithers' own choices animate as it makes them. A row in the sidebar shows where it is: Analyzing, In review, Setting up, Ready.

</TabItem>

Not applicable: start the TUI in any checkout.
