---
title: Review a change
description: Run the ordinary review flow over a repository change.
---

Start `/review` in the repository chat, or use the same registered flow from the CLI:

```sh
smthrs flow start review --payload '{"repo":"."}'
```

The flow reviews the working copy, including jj changes. Supply `commit`, or both `from` and `to`, to review pinned revisions. It independently verifies findings, marks incomplete reviews, and returns a walkthrough in the embedded run card. The host supplies authentication, model aliases, permissions and budgets just as it does for other flows. Cancellation and execution history use the normal run controls.

`narrate: false` keeps the deterministic reading order; `verify: false` skips independent adjudication. Review and verification use the configured `sol` alias, and narration uses `luna`.

`smthrs review <pattern>` runs declared model-review targets in the build graph. That build verb remains separate from the repository `/review` flow.
