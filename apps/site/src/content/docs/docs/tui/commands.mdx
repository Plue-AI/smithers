Type `/` to browse commands. Up/Down choose, Tab completes, Enter runs, Esc closes.

| Command | Action | Details |
| --- | --- | --- |
| `/model [query]` | Pick a model. | [Guide](/docs/learn/models/) |
| `/theme` | Pick a theme. | [Guide](/docs/tui/views/) |
| `/thinking [level]` | Set the reasoning effort. | [Guide](/docs/learn/models/) |
| `/new` | Start a new conversation. | [Guide](/docs/learn/chat/) |
| `/resume` | Resume a conversation. | [Guide](/docs/learn/chat/) |
| `/fork` | Fork from an earlier message. | [Guide](/docs/learn/chat/) |
| `/conversation` | Show the conversation file and tokens. | [Guide](/docs/learn/chat/) |
| `/compact` | Drop the oldest context. | [Guide](/docs/learn/chat/) |
| `/name <name>` | Name this conversation. | [Guide](/docs/learn/chat/) |
| `/copy` | Copy the last answer. | [Guide](/docs/learn/chat/) |
| `/summary` | Review this conversation. | [Guide](/docs/learn/review-a-change/) |
| `/tabs` | Review background work. | [Guide](/docs/learn/background-work/) |
| `/chat` | Return to chat. | [Guide](/docs/tui/views/) |
| `/filter` | Show or hide workers and kinds of rows. | [Guide](/docs/tui/views/) |
| `/grep [text]` | Show only rows containing text. | [Guide](/docs/tui/views/) |
| `/ui [id]` | Open a custom view. | [Guide](/docs/tui/extend/) |
| `/smithers` | Flows and runs. | [Guide](/docs/learn/run-a-flow/) |
| `/flows` | Run a flow. | [Guide](/docs/learn/run-a-flow/) |
| `/flow <name> [json\|key=value]` | Run a flow. | [Guide](/docs/learn/run-a-flow/) |
| `/agent [name] [prompt]` | Run a custom agent. | [Guide](/docs/how-it-works/agents/) |
| `/retry <id>` | Retry a stopped worker or flow. | [Guide](/docs/learn/background-work/) |
| `/stop <id>` | Stop a worker or flow. | [Guide](/docs/learn/background-work/) |
| `/hotkeys` | Show the keys. | [Guide](/docs/tui/keys/) |
| `/quit` | Quit. | [Guide](/docs/tui/cli/) |
| `/exit` | Alias for `/quit`. | [Guide](/docs/tui/cli/) |

Repository flows also appear in the menu. `/model`, `/thinking`, `/flow`, and `/agent` complete their arguments. Start a line with `!` to run a shell command and add its output to the conversation, or `!!` to keep it out.
