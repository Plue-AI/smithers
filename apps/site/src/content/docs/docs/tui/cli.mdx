```text
smthrs tui [directory] [--model provider:modelId] [-c | -r] [-p "prompt"] [--approve all|ask|deny] [--budget-tokens n]
```

From a source checkout, use `bun run tui` with the same arguments.

| Option | Short | Effect |
| --- | --- | --- |
| `directory` | | Working directory; defaults to the current one. |
| `--model provider:modelId` | `-m` | Chat model; overrides `SMITHERS_TUI_SEAT`. |
| `--continue` | `-c` | Continue the latest conversation in this directory. |
| `--resume` | `-r` | Pick a conversation to continue. |
| `--print "prompt"` | `-p` | Answer one prompt, print it, and exit. |
| `--approve all` | | Run edits, commands, and network calls. The default. |
| `--approve ask` | | Ask first. Interactive only. |
| `--approve deny` | | Refuse them. |
| `--budget-tokens n` | | Refuse a model call when its estimated total would exceed `n` tokens per turn or worker. Unbounded by default. |
| `--help` | `-h` | Show options. |

The token budget uses reported usage to estimate the next call. An admitted call can consume more than its estimate.

## One answer

```bash
smthrs tui /path/to/project -p "Explain how the search index is built."
```

Exits 0 on an answer and 1 on failure or cancellation. `--approve ask` is refused in this mode.

## Runtime

`smthrs tui` tries `SMITHERS_TUI_BIN`, an installed binary, Bun, then Node 26.4 or later. Interactive compiled builds need a writable, executable `TMPDIR`.

```bash
cargo build --locked --release -p smithers-ffi --bin smithers-jj-export
node packages/smithers/scripts/build-tui.mjs
SMITHERS_WORKSPACE_JJ_EXPORT_BINARY="$PWD/target/release/smithers-jj-export" \
  node --experimental-ffi --disable-warning=ExperimentalWarning packages/smithers/dist/tui/main.js /path/to/project
```

## Exit

`/quit` or `/exit`. Ctrl+D exits with an empty editor; Ctrl+C twice within 500 ms exits. Stop background work with its own controls first.
