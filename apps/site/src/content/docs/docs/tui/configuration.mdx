Use environment variables for defaults; command-line flags override them.

## Providers

| Variable or account | Purpose |
| --- | --- |
| Signed-in Codex CLI account | ChatGPT subscription; listed first in the model picker. |
| `SMITHERS_OPENAI_AUTH=chatgpt` | Use the subscription route. |
| `OPENAI_API_KEY` | OpenAI. |
| `ANTHROPIC_API_KEY` | Anthropic. |
| `OPENROUTER_API_KEY` | OpenRouter. |
| `MOONSHOT_API_KEY` | Moonshot/Kimi. |
| `GEMINI_API_KEY` or `GOOGLE_API_KEY` | Gemini. |
| `CEREBRAS_API_KEY` | Cerebras; preferred for chat when set. |
| `SMITHERS_OPENAI_COMPATIBLE_BASE_URL` | An OpenAI-compatible endpoint. |

Worker completions and monitors require a connected ChatGPT subscription, directly or through the account pool. They need no separate judge key.

## Settings

| Variable | Default |
| --- | --- |
| `SMITHERS_TUI_SEAT` | Chat model; `--model` wins. |
| `SMITHERS_TUI_WORKER_SEAT` | Background worker model. |
| `SMITHERS_TUI_WORKER_SEATS` | Fallback models for workers, comma-separated. |
| `SMITHERS_TUI_WORKERS` | Six workers at once; more wait in order. |
| `SMITHERS_TUI_APPROVE` | `all`; also `ask`, `deny`. `--approve` wins. |
| `SMITHERS_TUI_BUDGET_TOKENS` | Unbounded. Checks estimated tokens before each model call, per turn and worker; `--budget-tokens` wins. |
| `SMITHERS_TUI_SESSION_DIR` | Where conversations are stored. |
| `VISUAL`, then `EDITOR` | Editor for Ctrl+G; falls back to `nano`. |
| `SMITHERS_TUI_BIN`, `SMITHERS_BUN` | Which TUI build and Bun the launcher uses. |
| `SMITHERS_WORKSPACE_JJ_EXPORT_BINARY` | Native helper for flows. |

The theme is saved in `~/.smithers/tui/theme`.

## Instruction files

Every turn includes `~/.smithers/agent/AGENTS.md`, then, from the repository root down to the working directory, the first of `AGENTS.override.md`, `AGENTS.md`, or `CLAUDE.md` in each directory.

## Stored conversations

Conversations are saved under `~/.smithers/tui/sessions/<directory>--<hash>/` as private JSONL files. Credential-shaped text is redacted; file patches are kept exactly so undo works. An incomplete final line is dropped before the conversation continues. Damage earlier in the file renames it `.damaged` and leaves it out of the picker. Treat the folder as private project data.
