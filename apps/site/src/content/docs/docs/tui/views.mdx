## Tabs

Chat, Summary, workers, flow runs, and custom views each have a tab. Ctrl+] moves forward; Ctrl+[ or Ctrl+Left moves back. Ctrl+Right also moves forward. Ctrl+\ returns to Chat; Ctrl+Y returns from a worker to its parent. Click a tab to open it. Agent tabs focus their composer; printable keys type. Tab selects transcript rows, arrows move, and Alt+U undoes the selected change. Esc returns to Chat.

Some terminals send Ctrl+[ as Esc; use Ctrl+Left there. macOS may reserve Ctrl+Left/Right for switching Spaces.

## Filter the transcript

`/filter` shows or hides kinds of row. Workers show as cards in the chat; Ctrl+S shows them all. `/grep text` shows matching rows; `/grep` clears it. Filters change the view only.
