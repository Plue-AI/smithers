## Tabs

Chat and Summary stay pinned, followed by counts and only the focused run or custom view. Finished runs open from Summary. Ctrl+] moves forward; Ctrl+[ or Ctrl+Left moves back. Ctrl+Right also moves forward. Ctrl+\ returns to Chat; Ctrl+Y returns from a worker to its parent. Click a tab to open it. Agent tabs focus their composer; printable keys type. Tab selects transcript rows, arrows move, and Alt+U undoes the selected change. Esc returns to Chat.

Some terminals send Ctrl+[ as Esc; use Ctrl+Left there. macOS may reserve Ctrl+Left/Right for switching Spaces.

Ctrl+T opens a one-row timeline over the current view. Esc closes it. The idle composer and worker header each use two rows; decisions and recovery controls keep their space when the transcript is clipped.

## Filter the transcript

`/filter` shows or hides kinds of row. Workers show as cards in Chat; the strip shows one live count, and Ctrl+S shows them all. There is no automatic worker rail. Off-screen settlements produce a toast: Enter opens the run and clears it. A new attempt replaces its notice; restart never restores notices. `/grep text` shows matching rows; `/grep` clears it. Filters change the view only.

## Theme

The TUI uses Paper with the same teal accent as the browser app.

## Footer and details

The footer shows the project and branch, clipped from the left, followed by key hints. Context use appears from 70%, such as `ctx 74%`. Ctrl+O shows session input and output tokens including agents, with dollars marked estimated. Summary rows show names, models, and clocks.
