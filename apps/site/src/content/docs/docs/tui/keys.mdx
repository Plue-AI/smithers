Press **?** with an empty editor to see the keys for where you are. **Esc** or **?** closes the list.

Agent tabs open in the composer; printable keys type. Use the Alt chords for agent actions; the single-letter aliases apply to explicit rows in other views. Tab selects agent transcript rows; typing and pasting return to the composer. Stop asks for one confirmation per run. Ctrl+T inspection returns to the previous view, scroll and composer target on Esc; after switching tabs, Esc keeps the opened tab. Sending a message shows the new turn.

## Editor and mouse

Ctrl+A/Ctrl+E move to the beginning/end of a line. Shift+Left/Right selects text in the composer, search, and text fields; typing replaces the selection. Ctrl+W deletes a word and Ctrl+U deletes to the start of the line. Ctrl+K belongs to search. Drag text to copy a selection; click tabs, worker rows, cards, or status actions to open/invoke them. Scroll with the mouse or PageUp/PageDown.

Ctrl+C clears the editor; twice within 500 ms exits. Ctrl+D exits only with an empty editor. Approval keys arm only after the editor is empty and their 400 ms guard has elapsed. Agent tabs use Alt+Y, Alt+N and Alt+A; plain letters type.

Repository and runtime [extensions](/docs/tui/extend/) add keys under their owner in the popup. Built-in keys and text-editing bindings cannot be shadowed.
