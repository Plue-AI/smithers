Find an app command. You do not need the CLI to use the app.

## Open the command list

1. Open **Chat** with Command-K on macOS or Control-K on Windows and Linux. Press it again to close Chat.
2. Type `/help` and press Enter.
3. The Commands card lists the commands and their descriptions.

See [Flows reference](flows.md#find-a-command) to filter the command menu.

See the [install page](https://smithers.sh/docs/installation/).
