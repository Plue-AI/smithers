# Coding account privacy

Signing out or switching accounts removes saved coding-account requests,
including connection, device sign-in, pool order and revocation metadata.
Requested, completed and failed requests leave in the same verified privacy
transaction as the account's other private data, including after reopening.
Changing sign-in providers also clears these requests.

Late replies cannot restore the previous account's requests. Temporary
identity outages and rechecking the same account preserve recovery. Credentials
remain write-only, and a failed privacy cleanup remains a failure.
