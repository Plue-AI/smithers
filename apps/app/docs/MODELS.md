# Models

The owner sets Fast model, Coding model and Decisions in Settings. Open
`/agents` to see the planner, implementer, reviewer and app agent. Change model
saves the choice immediately in the install's existing settings.

The Agent card also holds named model records. New and Edit use the shared
form; Test uses the host model route. Records contain a credential name, never
its secret value. Assigning a record copies its binding into the agent setting.
Removing the record keeps an already assigned binding.

Model actions stay out of Help and agent tools. Members can read the factory's
model choices; only the owner's browser session can change them. The app agent
uses the coding model when the fast key is absent.

Instructions open as repository files. Instruction activation and changing the
model of the next call in an already running TODO require the factory runtime's
verified revision and per-call role bindings.
