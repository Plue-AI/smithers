# @smthrs/ui-styleguide — src

Shipped-as-source `.ts` modules: the package's export map points straight at
`src/index.ts` (no build step, no dependencies). Every relative specifier here
carries its `.ts` extension, because `flows/review` loads this package under
Node ESM, where an extensionless specifier does not resolve.

The contract lives one directory up:

- [`../docs/api.md`](../docs/api.md) — the exports and their input contracts.
- [`../docs/theming.md`](../docs/theming.md) — the selection axes, the cascade,
  and the WCAG AA table.
- [`../README.md`](../README.md) — what the package is and how to run it.

`src/themes/*.ts` other than `fucory.ts` are generated by
`packages/smithers/ui/ui-styleguide/scripts/generate-theme-registry.ts`. A hand edit there survives only until the
next regeneration; `tests/generatedThemes.test.ts` compares them byte for byte.
