title: "Paper source"
description: "The retained Paper palette and its pinned syntax and terminal inputs."
---

The registry contains one read-only `paper` theme with light and dark variants.
Its portable semantic tokens in `scripts/paperTokens.ts` match the app's Paper tokens.
`generate-theme-registry.ts` reads `@shikijs/themes` 4.4.3 for Night Owl syntax
and ANSI colors, the existing syntax fallback for Paper. It writes `src/themes/paper.ts`.

```sh
node --experimental-strip-types scripts/generate-theme-registry.ts
node --experimental-strip-types scripts/generate-theme-registry.ts --check
```

`--check` compares generated bytes without rewriting them. Keep app and shared
semantic tokens aligned and run the contrast tests when changing these inputs.
Host-specific styling remains supported: [override a token](../guides/override-a-token.md).

The decorative collection is deferred in [#3403](https://github.com/smithersai/smithers/issues/3403).
